Project Concept

From Raw Records to Actionable Patient Intelligence

The platform brings structured patient records, historical information and available clinical documents into one system. AI and retrieval mechanisms are then used to organize, understand, visualize and prioritize the information.

01

Collect

Import patient, encounter, disease, laboratory, medication, visit and expenditure records.

02

Organize

Clean, validate and structure raw records into a consistent patient-centric data model.

03

Retrieve

RAG retrieves relevant historical information and contextual evidence when needed.

04

Understand

AI combines current information with retrieved context to generate understandable insights.

05

Prioritize

Machine-learning models classify cases according to the project's validated risk methodology.

06

Act

Controlled workflows create follow-up actions, notifications and continuous re-evaluation.

System Architecture

Complete End-to-End Architecture

Each layer has a specific responsibility. Structured data is handled by TiDB, contextual retrieval by Qdrant-based RAG, AI reasoning by Gemini, and risk prediction by a dedicated machine-learning layer.

Core Features

Everything the Platform Can Do

The features are connected to the same patient context so that visualization, retrieval, risk analysis and follow-up are part of one continuous workflow.

Patient Data Organization

DATA

Converts raw records into structured patient, encounter, disease, laboratory, medication, procedure and payment information.

Interactive Dashboard

VISUAL

Displays patient counts, visits, admissions, disease distribution, risk distribution, trends and hospital utilization.

Patient Search

SEARCH

Search a patient and immediately view their available history, current information, risk, expenditure and follow-up status.

Longitudinal Patient Timeline

TIME

Shows how the patient's visits, conditions, risk and available information change across multiple encounters.

Risk Stratification

ML

Uses a validated machine-learning approach to categorize cases into low, medium and high-risk groups according to the project methodology.

Risk Trend Detection

TREND

Compares historical risk scores to identify stable, increasing, decreasing or rapidly changing risk trajectories.

Explainable AI

XAI

SHAP identifies the important model features contributing to the risk prediction and presents them in an understandable form.

Hospital Expenditure Analytics

ANALYTICS

Visualizes how much a patient spent across hospital visits, average expenditure per visit, department expenditure and expenditure trends.

Disease & Department Analysis

INSIGHT

Compares disease categories, visit frequency, risk distribution, department activity and available expenditure patterns.

Natural Language Analytics

AI

Allows users to ask questions about patient and hospital data using natural language and routes the question to structured retrieval or RAG.

Adaptive Follow-up

ACTION

Uses risk, trends, available patient context and predefined workflows to prioritize appropriate administrative follow-up.

Report Generation

EXPORT

Generates downloadable patient summaries, filtered analytics, risk reports and visualized datasets in suitable formats.

Technology Stack

Technologies and Their Exact Responsibilities

Each technology has a defined role so that the system remains maintainable instead of using multiple technologies for the same task.

Frontend React + Vite

Dashboard, patient search, charts, timelines, filters and reports.

Backend Spring Boot

REST APIs, authentication, business logic, RAG orchestration and notification workflows.

Database TiDB

Patients, encounters, diseases, laboratory data, visits, payments, risks and follow-ups.

Vector Database Qdrant

Stores embeddings and retrieves relevant contextual patient information.

LLM Gemini API

Contextual summarization, natural-language analytics and grounded AI generation.

Embeddings BGE Open-Source Model

Converts text/document chunks into vectors for semantic retrieval.

Machine Learning Python + Scikit-learn / XGBoost

Risk classification and patient-level predictive analysis.

Explainability SHAP

Identifies the features contributing to individual risk predictions.

Deployment Vercel + Railway

Frontend and backend deployment for the complete full-stack application.

System Reliability

AI With Data and Workflow Controls

Evidence Grounding

AI responses are generated using retrieved project data rather than relying only on model-generated assumptions.

Agent Verification

Generated insights and follow-up actions pass through an evidence-checking step.

Human Review

High-priority cases can be presented for professional review rather than allowing autonomous medical decisions.
